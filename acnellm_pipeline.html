Route Flags — Tác động lên Pipeline
repeated_question
→ Yield prefix "Như mình đã chia sẻ, " trước LLM tokens
Trigger: normalize text khớp với user turn trong 6 turns gần nhất
language_switch
→ Build query_en (pure EN) + RRF fuse cả VI + EN queries trong RAG
Trigger: detected_language ≠ previous_language (cả hai đều known)
emotional_distress
→ Yield prefix "Mình hiểu mụn có thể ảnh hưởng đến tâm lý nhiều lắm — " trước LLM
Trigger: từ khoá tự ti, xấu hổ, stress, buồn, chán, mất tự tin...
crisis_signal
→ Yield crisis empathy prefix + override intent → clarify (safety_clarify)
Trigger: từ khoá tự tử, tự sát, không muốn sống
product_safety_check
→ Inject 8 ingredient safety terms vào safety_terms → trigger safety pass retrieve guideline chunks về contraindication
Trigger: retinol, AHA, BHA, BPO, kết hợp, dùng chung...
urgency_red_flag
→ Append 🚨 suffix "đến cơ sở y tế ngay" sau LLM response
Trigger: đau nhiều, sưng lớn, rỉ dịch, lan rộng, sốt, nang lớn, red_flags từ normalizer
progress_followup
→ route_metadata.is_progress_followup=True, accumulated_clinical_score++
Trigger: tuần rồi, không đỡ, đỡ hơn, không hiệu quả, routine trước...
multi_condition
→ Append ⚠️ suffix gợi ý bác sĩ da liễu (điều trị chồng chéo)
Trigger: rosacea, eczema, viêm da, kích ứng, dị ứng
ambiguous_intent
→ Micro-classifier được gọi để tiebreak; nếu vẫn tie → prefer knowledge
Trigger: rule scores quá gần nhau (confidence < 0.65 và các intent cạnh tranh)
SSE Events — Format & Thứ tự
token
[Optional] Pre-stream prefix (crisis/emotional/repeated) — yield trước LLM
token
LLM stream tokens (nhiều events, mỗi token = 1 event)
token
[Optional] Safety suffix (retinoid/Rx/urgency/multi_condition warnings)
token
[Optional] Partial follow-up question (kind=partial only)
citation
Per-chunk citation: chunk_id, source, title, url, score, text[0:220] (0–N events)
done
mode, latency_ms, used_chunks[], session_id, evidence_quality, primary_intent, route_flags[]
error
[Exception path] error message + done event với mode=error
Format: data: {"event": "<type>", "data": <payload>}\n\n
Thay đổi so với phiên bản trước

Completeness Check — Decision Tree
too_short → BLOCK
word_count < 4 AND no signal AND no history AND not in intake flow → hỏi mô tả thêm
missing_core → BLOCK
Có signal nhưng thiếu lesion_types hoặc distribution, và field đó chưa từng hỏi → hỏi 1 field
partial → LLM + append câu hỏi (M8 MỚI)
Đủ để tư vấn sơ bộ (_has_enough_to_answer=True) nhưng vẫn thiếu field phụ → tư vấn luôn, hỏi thêm ở cuối
sufficient → LLM tư vấn bình thường
Đủ thông tin: lesion_types rõ OR inflammation_level rõ OR distribution rõ (bất kỳ 1 trong 3)
