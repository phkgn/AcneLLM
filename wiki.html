Chat Flow — SSE Stream

Input
GET /api/v1/chat/stream
Client gửi ?message=...&session_id=...&mode=auto. Qua RateLimitMiddleware → APIKeyMiddleware → RequestLoggingMiddleware.
Intake
run_intake() — chat/intake.py
NFC normalize → load session history → resolve mode → normalize (regex extract age/lesion/meds/...) → fold_history_facts → pre_check (injection + PII) → genital check → OOD scope check → complaint detect → completeness check → ClinicalQueryPlanner.plan()
Retrieval
retrieve_for_chat() — chat/_retrieval.py
Build query VI (+ EN nếu bilingual) → DiskCache TTL 1h → HybridRetriever.retrieve() → safety pass (guideline filter) → Cross-encoder rerank (top_k=3) → drop_noisy_chunks()
Prompt
PromptBuilder.build() — llm/prompt_builder.py
Jinja2 template stream_user.j2 — escape injection markers → sanitize chunk text → context block (max 4500 chars, source badges) → history block (filter genital turns)
Generation
OllamaBackend.stream_text() — llm/ollama_backend.py
POST /api/chat stream=True → yield token SSE events. Fallback 3B nếu runner terminated.
Safety
get_safety_suffix() — chat/_safety.py
Append warning nếu: pregnant + retinoid mention → urgent warning. Rx drug mention → bác sĩ reminder. age < 12 → nhi khoa. Urgency red flag → 🚨 suffix.
Output
SSE events + persist
Yield citation events → persist session JSONL → AuditStore.log() SQLite → yield done event với {mode, latency_ms, evidence_quality}

Build KB Pipeline

Trạng thái: Chunk step hoàn tất (2026-05-21)
26,864 chunks · 0 broken links · 0 unknown source_type · 33.7s
Step 1
Crawl → documents.jsonl
python scripts/crawl_all.py — Async fetcher + Playwright + PubMed API. Rate limit per domain. Dedup URL + content hash. Quality filter. Output: data/raw/documents.jsonl
Step 2 — --step chunk
Chunk → chunks.jsonl (3 phases)
Phase 1: clean_vi_text → VietnameseChunker (dedup=False) → filter: min_chars, _is_acne_chunk (signals VI+EN, CJK check, boilerplate), language filter
Phase 2: Cross-doc dedup — sort by trust_level (high first) → exact hash + top-20 word fingerprint shingling
Phase 3: Rebuild chunk_id / position / prev_chunk_id / next_chunk_id SAU filter → 0 broken links
Step 3 — --step embed
Embed → ChromaDB
Load chunks.jsonl → Embedder (Vietnamese_Embedding dim=1024, GPU) → ChromaStore.upsert() batches. Idempotent — có thể resume nếu interrupt. Cần chạy trên máy (GPU)
Step 4 — --step bm25
Build BM25 Index
underthesea tokenize + stopword removal → BM25Okapi → pickle với SHA-256 checksum. Output: data/bm25_index.pkl

RAG System

Query → Embed query → Dense (Chroma, dist≤0.48)
Query → VI tokenize → Sparse (BM25Okapi)
Dense hits Sparse hits → RRF Fusion k=60 → Trust Boost → Score prune ≥0.015
top-10 pool → Cross-encoder rerank → top-3 final → drop_noisy_chunks

Guardrails

🚫
Injection Detection
80+ phrases EN + VI có/không dấu + teencode + special tokens như [system], <|user|>
🧭
OOD Scope Check
2 tầng: keyword (200+ acne terms vs out-of-scope) + embedding cosine vs acne centroid (threshold 0.25). Fail-open.
💊
Drug Checker
drugs_acne.yaml + OpenFDA API fallback (cache 24h). Check cross-interactions, pregnancy category X, contraindications.
🔒
Genital Scope
Refuse cứng khi detect vùng sinh dục/hậu môn — chạy trước OOD check để tránh false negative.
🛡️
Post-check Rules
Rewrite retinoid nếu pregnant, inject "đi khám" nếu severe, xóa recommendation nặn/lăn kim, drug allergy red_flag.
🔍
PII Detection
CMND/CCCD, SĐT VN, email, địa chỉ, số tài khoản — chỉ log cảnh báo, không từ chối.
