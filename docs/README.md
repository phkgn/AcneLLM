# docs/

Tài liệu vận hành và cấu hình cho hệ thống AcneLLM (quy tắc chung: mã nguồn trong `src/acne_llm/` là nguồn chuẩn).

| File | Nội dung |
|---|---|
| `ARCHITECTURE_TRUTH.md` | Kiến trúc runtime, luồng xử lý intake/fallback, safety và lưu trữ phiên |
| `config_reference.md` | Mô tả các trường cấu hình trong `Settings` (`src/acne_llm/config.py`) |
| `DOCKER_QUICKSTART.md` | Hướng dẫn chạy hệ thống bằng Docker Compose |
| `RELEASE_ARTIFACTS.md` | Danh sách gói GitHub Releases (GGUF, KB snapshot) và cách khôi phục |
