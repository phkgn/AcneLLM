  1. Pre-model correctness: normalizer, router, state merge.
  2. Safety boundary: frontend stream bỏ full post-check/DrugChecker.
  3. Evidence integrity: index drift và citation không claim-level.
  4. Model contract: system/prompt và train/inference lệch.

Model có lỗi factual, nhưng thay model đơn thuần sẽ không sửa được ba nhóm đầu.

3 · Model & RAG audit

Hybrid RAG thật; lineage artifact không khép kín

Điểm này phân biệt “có pipeline RAG” với “có một corpus/index tái lập và kiểm chứng được”. Baseline đạt vế đầu, chưa đạt vế sau.

Retrieval mechanics

  • Dense cosine trên Chroma + BM25 token hoá tiếng Việt; lấy candidate rồi hợp nhất bằng RRF k=60.
  • Source/trust/authority boost, relative threshold, safety-oriented pass, cross-encoder sigmoid rerank.
  • Top context thường 3, clinical có thể 5; context cap 6.000 ký tự, mỗi chunk có title/source/chunk ID.
  • Citation SSE là các chunk đã cấp cho model—không phải bằng chứng model thật sự dùng chúng.

Corpus nguồn

documents.jsonl: 6.835 docs (4.598 EN, 2.237 VI), gồm PubMed reviews, nguồn y khoa Việt/Anh, blog, AAD và NICE. Chunker theo đoạn/câu, mục tiêu 200 từ, overlap 40, min 50.

Định dạng train chủ yếu <raw_user_message>; inference dùng <user_data>, clinical summary, RAG context, history và task. Generator code có default DeepSeek nhưng metadata artifact final là MiniMax-M3.

P2 · Reproducibility

  • Model card, base/adapter/merge hashes.
  • Align train/inference prompt contract.
  • Eval split độc lập theo safety/multi-turn.
  • Trace dùng cùng execution graph thực.

P3 · Ops & latency

  • Auth/CORS non-dev defaults.
  • Readiness kiểm tra index lineage.
  • Stage metrics, cache/batch reranker.
  • Production server/process lifecycle.
